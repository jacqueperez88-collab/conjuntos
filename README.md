# 📐 Teoría de Conjuntos — Matemática General

Página web interactiva para estudiantes de **Matemática General**
(Universidad Nacional del Comahue · 2.º cuatrimestre 2026).

Basada en el apunte de cátedra de la unidad **Conjuntos**.

## 🔗 Link para alumnos

👉 [jacqueperez88-collab.github.io/conjuntos](https://jacqueperez88-collab.github.io/conjuntos/)

Sitio gratuito alojado con **GitHub Pages** — no requiere instalar nada,
se abre desde cualquier navegador o celular.

## 📚 Contenido de la página

| Sección | Temas |
|---------|-------|
| Conceptos básicos | Conjunto, elemento, pertenencia (∈ / ∉), conjunto universal |
| Determinación | Por extensión, por comprensión, diagramas de Venn |
| Conjuntos especiales | Terna, par, unitario y conjunto vacío (∅) |
| Inclusión e igualdad | Subconjuntos (⊆), diferencia entre ∈ y ⊆ |
| Operaciones | Intersección, unión, diferencia, diferencia simétrica y complemento |
| Conjunto de partes | P(A) y todos sus subconjuntos |
| Cardinal | n(A), fórmula de inclusión-exclusión |
| Ejercicios | Casos particulares del apunte con respuestas desplegables |

## 🎮 Herramientas interactivas

- **Verificador de pertenencia**: el alumno escribe una letra y ve si ∈ o ∉ M.
- **Laboratorio de operaciones**: diagrama de Venn donde las regiones se
  iluminan al elegir ∩, ∪, −, △ o complemento.
- **Caso del club deportivo**: problema completo de cardinal con 3 conjuntos,
  diagrama y todas las regiones resueltas.
- **Ejercicios autocorregibles**: respuestas ocultas que se revelan al hacer clic.

## 🛠️ Cómo actualizar la página

1. Editar `index.html` (toda la página está en ese único archivo).
2. Subir los cambios con **Add file → Upload files** (o editar con el lápiz ✏️).
3. GitHub Pages actualiza el sitio automáticamente en ~2 minutos.
   Si no se ven los cambios, refrescar con `Ctrl + F5`.
