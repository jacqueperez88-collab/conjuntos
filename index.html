Conceptos básicos

Un conjunto es una colección de elementos diferentes, que pueden ser concretos o abstractos. Los elementos se representan con letras minúsculas y los conjuntos con letras mayúsculas. a: pantalla   b: teclado   c: ratón  →  A = {a, b, c}

Pertenencia ∈

¿El elemento está en el conjunto?

Dado el conjunto M = {a, e, i, o, u}:

a ∈ M   ·   b ∉ M

Se lee: “a pertenece a M” · “b no pertenece a M”.

02

Determinación de un conjunto

Por extensión

Uno a uno

Se enumeran todos los elementos del conjunto entre llaves.

M = {a, e, i, o, u}

Si es infinito, se cierra la llave tras puntos suspensivos para indicar que no hay último elemento: ℕ = {1, 2, 3, 4, …}. Si es finito, los puntos suspensivos abrevian hasta el último elemento: P = {a, b, c, …, z}.

Por comprensión

Una propiedad común

Se especifica una propiedad que cumplen todos los elementos. El símbolo / significa “tal que”.

M = {x / x es vocal del abecedario}

Los múltiplos de 2 menores que 14 quedan: A = {x / x = 2k, k ∈ ℕ, 1 ≤ k ≤ 6}

Diagrama de Venn

Es una representación gráfica de los conjuntos: cada conjunto se simboliza con una curva cerrada, y el universal con un rectángulo. Los elementos se ubican dentro de su región.

El conjunto vacío cumple un papel importante en la teoría y tiene símbolo propio: ∅. K = {x / x es diagonal del triángulo abc} = { } = ∅ Puesto que carece de elementos que lo distingan, el conjunto vacío es siempre el mismo: decimos el conjunto vacío, no un conjunto vacío.
04

Inclusión e igualdad

B está incluido en A si todo elemento de B pertenece a A. B ⊆ A ⟺ ∀x ∈ B ⟹ x ∈ A

Ejemplo

Con B = {2, 3, 4} y A = {1, 2, 3, 4, 5}:

B ⊆ A — todos los elementos de B están en A.
A ⊈ B — pues 1 ∈ A pero 1 ∉ B.

∈

Pertenencia

Vincula un elemento con un conjunto.
a ∈ M  ·  b ∉ M

⊆

Inclusión

Vincula dos conjuntos entre sí.
B ⊆ A  ·  A ⊈ B

Igualdad: dos conjuntos A y B son iguales si y solo si cada uno está incluido en el otro. A = B ⟺ A ⊆ B y B ⊆ A Ej.: A = {4, 5, 6}, B = {3, 4, 5, 6}, C = {4, 5, 6} → A ≠ B (porque 3 ∈ B y 3 ∉ A), pero A = C.

∀A, ∅ ⊆ A — el conjunto vacío está incluido en todo conjunto.

Notas y propiedades

DisyuntosA ∩ B = ∅ ⟹ A y B son disjuntos.
Ej.: pares ∩ impares = ∅ · ℚ ∩ I = ∅
IntersecciónA ∩ A = A
A ∩ B = B ∩ A
A ∩ (B ∩ C) = (A ∩ B) ∩ C
UniónA ∪ A = A
A ∪ B = B ∪ A
A ∪ (B ∪ C) = (A ∪ B) ∪ C
DistributivasA ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
ComplementoA ∪ A′ = U  ·  A ∩ A′ = ∅
(A′)′ = A  ·  U′ = ∅  ·  ∅′ = U
De Morgan(A ∩ B)′ = A′ ∪ B′
(A ∪ B)′ = A′ ∩ B′
DiferenciaA − B = A ∩ B′
Si A ⊆ B ⟹ A − B = ∅
Si A ∩ B = ∅ ⟹ A − B = A
Dif. simétricaA △ B = (A ∪ B) − (A ∩ B)
A △ B = (A − B) ∪ (B − A)
06

Conjunto de partes P(A)

Dado un conjunto A, P(A) es el conjunto formado por todos los subconjuntos de A. P(A) = { X / X ⊆ A } Nunca es vacío: como ∅ ⊆ A y A ⊆ A, siempre ∅ ∈ P(A) y A ∈ P(A). Si A tiene n elementos, P(A) tiene 2ⁿ elementos.

Ejemplo: A = {a, b, c}

Sus 8 subconjuntos (pasá el mouse por cada uno):

∅{a}{b}{c} {a, b}{a, c}{b, c}{a, b, c}
07

Cardinal de un conjunto

Denotamos con n(A) al número de elementos del conjunto A: es su cardinal. También se escribe #A, Card(A) o |A|.

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
Si A y B son disjuntos:  n(A ∪ B) = n(A) + n(B)
n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A ∩ B) − n(A ∩ C) − n(B ∩ C) + n(A ∩ B ∩ C)

Ejemplo guiado

Con A = {−2, −1, 0, 1, 2} y B = {x / x es divisible por 2 y −5 < x < 5} = {−4, −2, 0, 2, 4}:

n(A) = 5  ·  n(B) = 5  ·  A ∩ B = {−2, 0, 2} → n(A ∩ B) = 3

🏆 El club deportivo — caso completo

En un club de 1000 socios, hay 800 que practican al menos un deporte entre fútbol, básquet y tenis.

  • n(F) — juegan al fútbol 400
  • n(B) — juegan al básquet 350
  • n(T) — juegan al tenis 300
  • n(F ∩ B) 100
  • n(B ∩ T) 130
  • n(F ∩ T) 80
800 = 400 + 350 + 300 − 100 − 80 − 130 + n(F ∩ B ∩ T)
⟹ n(F ∩ B ∩ T) = 60
